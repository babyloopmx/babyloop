Aviso de privacidad

Última actualización: 8 de septiembre de 2026

1. Quiénes somos

BabyLoop es un negocio personal de venta de ropa de bebé en México, operado por Miguel Ángel Martínez García. El responsable del tratamiento de datos es la misma persona, contactable en mikelangel.mg@gmail.com.

Este aviso cubre appn8n, la aplicación interna que usamos para automatizar la preparación de fotografías de producto.

2. Quién usa la aplicación

appn8n es de uso exclusivamente interno. La utiliza una sola persona —el titular del negocio— sobre su propia cuenta de Google. No está abierta al público, no tiene registro de usuarios y no recopila datos de clientes, visitantes ni terceros.

3. Qué datos accede

La aplicación solicita permisos sobre la cuenta de Google del propio titular:

  • Google Drive: leer las imágenes que el titular coloca en una carpeta designada, y escribir las versiones procesadas en otra carpeta de la misma cuenta. No accede a ningún otro contenido del Drive.
  • Gmail: enviar un correo de aviso desde la cuenta del titular hacia esa misma cuenta, indicando que una imagen quedó lista. No lee, ni analiza, ni almacena correo existente.

4. Para qué se usan

Únicamente para mejorar la presentación de las fotografías de producto —iluminación, fondo, color y nitidez— y para notificar al titular cuando el proceso termina. No se usan para publicidad, perfilado, entrenamiento de modelos ni ningún otro fin.

5. Con quién se comparten

Las imágenes se envían a la API de Google Gemini para su procesamiento, bajo los términos de Google. Fuera de eso, no compartimos, vendemos ni cedemos datos a ningún tercero.

6. Dónde se procesan y cuánto se conservan

El flujo corre en n8n Cloud, que ejecuta el proceso y no retiene las imágenes de forma permanente. Las fotografías originales y procesadas permanecen en el Google Drive del titular, bajo su control, y puede eliminarlas en cualquier momento. La aplicación no mantiene una base de datos propia.

7. Uso limitado de datos de Google

El uso que appn8n hace de la información recibida de las APIs de Google se apega a la Política de Datos de Usuario de los Servicios de API de Google, incluidos sus requisitos de Uso Limitado.

8. Cómo revocar el acceso

El titular puede retirar los permisos en cualquier momento desde la página de permisos de su cuenta de Google. Al hacerlo, la aplicación deja de funcionar de inmediato.

9. Cambios a este aviso

Si el funcionamiento de la aplicación cambia, actualizaremos este documento y la fecha que aparece arriba.
